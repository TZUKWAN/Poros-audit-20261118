## 本次发布修复的关键 bug（实机定位）

1. **重规划并发竞态**——目标从共享闭包变量迁到每运行 RunBinding
2. **重规划更新路径缺口**——内联 `.then` 完成路径补 replan 分支
3. **抽查态闸门自动通过时序**——attachOrchestrator 重置状态，start 前补绑
4. **digest 漂移（两次）**——先改归一化原文为主源；实机日志再定位槽位名/数量/值全漂移，最终 **digest 只锚定归一化原文**，强制体检 %10 路径随之实机触发

## 灰度与回滚

`settings.routingMode`：`legacy`（默认，只记不用零行为变化）→ `spot`（自检启用）→ `full`（双路路由+体检）。场景详情面板可切换；每档回滚账本数据无损。

## 已知边界（诚实清单）

- replay 重放分支代码就位且单测覆盖，实机未走到（需 tier=replay + digest 命中双条件自然累积）
- 模板B 先例以元数据形态呈现（schema 不落产出原文）；format 块不结晶；copied 事件无 schema 槽位
- 反应窗 timer 内存态（面板重启丢未决窗口）
