# Poros 连续工作交互实施与验证

本轮以 `507e2067` 为基线，落实已批准的 [PC 交互研究](PC_INTERACTION_RESEARCH.md)。原有单次任务、运行和审批继续承担真实执行，新会话负责把同一目标的后续请求连接起来。修改发生在原审查分支，保留公开 PR，不合并主分支，不改现有业务部署。

## 数据、地址和执行契约

- 新增 Conversation、RunFeedback、Task 会话/轮次/意图/父结果/上下文快照，以及 Artifact 修订关系。`20261124221000_conversations` 为增量迁移。每个旧 Task 回填独立会话；原输入、Run、输出和质量状态不重写。隔离旧库迁移探针已验证。
- `#/work/:conversationId?task=:taskId` 定位具体请求。超过最近 20 条的早期请求仍通过相同权限的 Task API 读取，只挂载一份结果及 SSE。会话历史可向前加载，工作列表分页和搜索。
- `/api/conversations`、`/api/conversations/:id` 按当前组织和项目权限读取。`POST /api/tasks` 兼容原调用并返回稳定 conversationId、turn 和 taskId。准入事务串行分配轮次，幂等回执返回原请求和审批标识。浏览器重试及刷新保留未确认受理请求的幂等标识；新请求采用内容与执行模式的稳定摘要，助手后来发布新版不会使原已受理回执失效。不同内容仍返回 409。
- 会话沿用助手标识和项目，发送时采用该助手当时已批准版本。每条 Task 独立固定连接修订、能力和同意。更换助手或范围需新建工作；项目接续使用接续者自己的权限和连接。
- Worker 等待同会话前序的排队、执行和真实待审批请求；已失败、取消或拒绝的请求保留其终态，不被当作成功。模型收到历史状态与错误，未完成操作不伪装完成。
- 上下文先保存实际历史快照，显式重试沿用该快照。每次执行和工具调用重新验证组织、项目、助手、连接及历史文件。原文件仍有权且可读时重新生成摘录，记录本次真实 FileUse。
- 每次最多新增 3 个附件，每个最多引用 1500 字；请求、历史结果、修改对象和摘录的组合最多 64000 字符。超限明确阻止后续模型调用，并提示选取所需材料新建。源码曾将日志脱敏的 16000 字限制用于结果保存，本轮已修正为对完整结果脱敏；原有日志限长保持。
- 本次评价写入 `/api/tasks/:id/runs/:runId/feedback`，不修改 Run.status、采纳决定和 Judgment。长期规则仍保留原有来源证据、冲突检查与独立审批。
- 草稿保存提交 expectedRevision。与服务端当前可编辑字段不一致时返回 409，浏览器保留本地文字并显示差异。发布申请另比较草稿和全部精确授权的 publicationRevision，防止冻结与已展示内容不同的版本。
- `/api/approvals/mine` 只返回本人的可访问申请；原 `/api/approvals` 和决策接口继续限制审阅角色并禁止自审。可按具体 taskId 定位。

## 实施边界

当前审批粒度是整条请求的列明敏感能力。执行中补充的信息作为下一条请求处理；界面没有声称能改写正在运行的调用。细粒度工具调用前暂停、自动恢复外部副作用、任意会话公开分享和任意 MCP 执行不属于本轮已实现契约。协作通过既有项目权限提供，发布与运行继续默认拒绝未授权能力。

供应商和模型可用性由真实连接测试决定。2026-11-24 22:53（北京时间）通过本轮 Poros 个人模型设置接口对指定 Gemini 通道执行一次真实生成探测：接口如实返回 passed=false、verified=false、NETWORK_ERROR，本机指定端口没有监听。前轮曾收到 403/503 与 VALIDATION_REQUIRED；本次没有得到上游 HTTP 响应，不能把历史错误当成本次结果。临时验证账号、凭证与数据库已随探针结束回收。

浏览器及执行回归使用明确的模型协议夹具，真实 PostgreSQL、S3、DSH 和工具实际运行。该证据验证工作流程和边界，不构成 Gemini、语义 Judge、Kdocs、IMA、TinyFish 真实业务产出的验收。后三项没有收到新的可用真实凭证。实体手机及原生 APK/IPA 未在本轮开发或验收，已有 PWA 继续复用同一应用。
